# SR2MOD — каталог разработки модов Space Rangers HD

Главная точка навигации по исходникам модов проекта FHD.

**Важно:** этот репозиторий содержит исторические архивы и индекс; активные исходники многих модов уже находятся в отдельных репозиториях аккаунта [Wolker2](https://github.com/Wolker2?tab=repositories). Присутствие архива или исходников не означает, что версия протестирована или является последней.

- [Правила сборки и публикации](docs/WORKFLOW_RU.md)

## Основные принципы

1. Не менять и не удалять ранее сохранённые рабочие версии без проверки.
2. В исходниках и модах, зависящих от Rangers.exe, поддерживать **старый и новый EXE**, выбор по хешу автоматически.
3. Каждый мод должен переключаться TEST ↔ RELEASE в обе стороны. Не выдумывать синтаксис конфига; подтверждённый пример FHD_SET использует `Script.FHDSETv1.BuildMode` в `CFG/Rus/Lang.dat` с `001=int result=0` (RELEASE) / `result=1` (TEST).
4. Исходники — в GitHub; проверенные готовые ZIP/RAR и большие ресурсы — в Google Drive.
5. Не публиковать приватные ключи, токены, пароли или служебные секреты.
6. Версия с именем TEST или более высоким номером не считается рабочей без проверки в игре.
