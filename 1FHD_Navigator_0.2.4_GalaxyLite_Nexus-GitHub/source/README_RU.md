# FHD_Navigator 0.2.4 — GalaxyLite: исправление текста маршрута (TEST)

Скриптовый Navigator для `AModGalaxyLite.rar`.

## Исправление 0.2.4

* Каждое изменение маршрута выводится в **собственную** строку `FHDNavigatorRouteInfo`, а не в строку QuestMarker. Текст задания QuestMarker не перезаписывается.
* Рамка Навигатора скрывается, если одновременно присутствует рамка QuestMarker; подпись Навигатора не отключается. Если QuestMarker отсутствует, отображается отдельная рамка Навигатора.
* При совпадении сохранённого состояния маршрута пустая подпись восстанавливается при следующем штатном событии на галактической карте.
* Когда маршрут не построен, выводится «Навигатор: выберите маршрут». Если выбранный маршрут не удалось распознать по штатным элементам, показывается краткое объяснение вместо пустоты.
* Контейнер подписи выведен выше рамки QuestMarker, чтобы не терять надпись за картинкой.

## Установка

1. Закройте игру.
2. Полностью удалите предыдущую папку `Mods\FHD_MODS\FHD_Navigator` (не удаляя другие моды).
3. Распакуйте `Mods` из ZIP в **корень игры**.
4. Включите `AModGalaxyLite` и `FHD_Navigator` в стандартном менеджере модов. Не нужны CMD, установщики, дополнительные DLL.

## Работа

Откройте галактическую карту и выберите системы обычным способом. При ручном построении маршрута Навигатор оценивает дни перелёта, число гиперпрыжков и нужных дозаправок. При расчёте учитываются начальный взлёт, гиперускоритель, штатная скорость, остаток топлива и полёт к дозаправочным пунктам. Расчёт полёта в системах приближённый — по прямой; время боёв, ожидание и будущие изменения обстановки не прогнозируются. При недостатке топлива или неизвестных размерах систем выдаётся предупреждение.

Работает только по **ручному маршруту**: если другой мод программно назначает составной маршрут и не раскрывает промежуточные системы в штатном интерфейсе, Navigator его не угадывает. Если несколько систем располагаются на одних экранных координатах, расчёт безопасно отклоняется.

## Совместимость и проверка

Архив не изменяет `AModGalaxyLite`, файлы QuestMarker, EXE игры и сохранения. В нём нет DLL, перехвата SetActive, хуков интерфейса или адресов EXE. Используются штатные вызовы интерфейса из скрипта по событиям карты; без фонового цикла и без проверки на каждом игровом ходе.

**Проверено статически:** сборка DAT, целостность архивов, названия элементов и восемь порядков слияния UI с GalaxyLite/QuestMarker. **Не проверено в запущенной игре Windows:** фактическая отрисовка рамки/надписи и точность маршрута. Попытка эмуляции RScript на EXE заблокирована отсутствующими модулями Python; результаты эмуляции не заявляются.

Для удаления закройте игру и удалите только `Mods\FHD_MODS\FHD_Navigator`.
