# Диагностика 0.2.4

Регрессия: в 0.2.3 NavLayout скрывал FHDNavigatorRouteInfo при наличии QuestMarker.
NavShow записывал FHDQuestRouteInfo, которую QuestMarker сам мог отключить или перезаписать.
Даже если маршрут оставался прежним, NavUpdate прекращал работу по совпадению подписи, не восстанавливая видимый текст.

Исправление: независимый FHDNavigatorRouteInfo всегда активен, NavShow работает только с ним.
Общая рамка QuestMarker обнаруживается без изменений её состояния. При наличии общей рамки скрывается только картинка собственной рамки Navigator.
Для сохранённой подписи маршрута потерянный текст восстанавливается из скрытой строки состояния по следующему событию карты.

Проверки: roundtrip DAT, структура GalaxyLite, отсутствие конфликтных имён, исходные обработчики, эмуляция интерпретатора при наличии EXE.
Полный запуск в игре и точность отображения на пользовательском экране не подтверждены.
