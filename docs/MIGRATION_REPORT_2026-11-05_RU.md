- Остальные архивы Drive ещё **не обновлены** до последних исходников на GitHub. Существующие 27 репозиториев содержат исторические исходники многих модов и требуют сверки текущих версий.
- Подключённые GitHub-действия не предоставляют создание нового репозитория; UpdateCheck размещён отдельно внутри SR2MOD, а не в новом репозитории.
- Отдельные исходники, которые были получены только как DLL без C/C++/RSON, не выдаются за восстановленный авторский код.
- Не было живого теста в игре; ни один импортированный TEST не объявлен RELEASE.
- В проверенной папке Drive видно 28 непосредственных архивов; ранее каталог модов обнаружил 29. Разница ещё требует проверки.

## Правила дальнейших обновлений

1. Для любой зависимости от Rangers.exe — поддержка старого и нового EXE; автоматический выбор по SHA-256.
2. Для всех модов — переключение TEST ↔ RELEASE в обе стороны проверенным конфигурационным механизмом.
3. Править только необходимое, сверять diff/SHA-256, не менять папку игры, не вводить запускаторов CMD.
4. GitHub хранит исходники и QA, Google Drive — готовые ZIP/RAR и крупные ресурсы.
5. Не публиковать приватные секреты и не объявлять рабочей версию, не проверенную в игре.

## Исправление структуры

По просьбе пользователя три импортированных проекта перемещены в отдельные одноимённые каталоги верхнего уровня (формат Nexus), без изменений содержимого файлов. Старые пути `projects/` и `imports/` больше не используются для этих пакетов. Настройки GitHub Actions обновлены на новые пути.
