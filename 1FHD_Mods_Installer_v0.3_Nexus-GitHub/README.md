Полный оригинальный архив установки сохранён без изменения байтов в `install/`. SHA-256 `3534a3025a057e27f9f1315b21aba1d08b2ce74cd172edb55f57c1a63bae4743`.

В `source/` распакованы 13 текстовых файлов с исходниками и документацией; повторов, картинок и готовых бинарников вне оригинального архива нет.

Ничего из прежних версий не удалено и не заменено. ZIP проверен, но запуск установленного мода в игре в этой операции не проводился.
