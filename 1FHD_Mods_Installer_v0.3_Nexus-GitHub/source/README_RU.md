# FHD Mods Installer 0.3 󢀔 каталог уже настроен

## Что важно

**Дополнительно создавать Google Apps Script и вставлять код НЕ НУЖНО.**
У тебя уже есть опубликованный каталог `FHD_UpdateCheck` из другого чата.
В этом выпуске его URL заранее внесён в `settings.json`.

Этот установщик поддерживает текущий формат INI-манифеста (`[Updater]`, `Schema=2`, `[Mod1]`...) и старый JSON-формат каталога. При запуске он запрашивает актуальные ID архивов с Google Диска и при установке повторяет запрос, чтобы не использовать устаревшие версии.

Источник архивов: https://drive.google.com/drive/folders/16iY_DzJk7X7NxmegMbqYURLl5C6Q8qTd

**Публикацию существующего Apps Script из этой среды проверить не удалось.** Поэтому работу по сети надо подтвердить на компьютере: в установщике должен появиться статус «ОНЛАЙН 󢀔 последние версии». Если статус «ОФЛАЙН», установка заблокирована, чтобы случайно не ставить старые архивы. Второй проект Apps Script для этого создавать не нужно.

## Что делать на Windows

1. Распакуй весь ZIP в отдельную папку.
2. Запусти `START_FHD_SETUP.cmd` 󢀔 появится окно установщика с карточками модов.
3. Выбери папку игры, в которой находится `Rangers.exe`.
4. Дождись проверки каталога; если нужно, нажми «Обновить каталог».
5. Отметь моды и нажми «СКАЧАТЬ И УСТАНОВИТЬ».

Или собери однофайловую оболочку EXE из проекта кнопкой `BUILD_EXE.cmd` (на Windows, где доступен компилятор .NET Framework). Изображения, настройки и скрипты должны оставаться рядом с EXE. Это ещё не полностью автономный один файл.

## Что не нужно делать

- Не открывай `script.google.com`, чтобы создавать второй Apps Script.
- Не копируй `FHD_Catalog_AppsScript.gs` в другой проект.
- Не нужно вручную менять `settings.json` для текущего каталога.
- Игрокам не нужен доступ к твоему Google-аккаунту и не нужно создавать скрипты.

## Автообновлятор обязателен

В текущей папке Google Диска при проверке 04.11.2026 **нет отдельного архива `FHD_UpdateCheck` / `FHD_AutoUpdater`**. Пока он не будет опубликован там и виден в онлайн-манифесте, установщик *специально не начинает установку*, чтобы не обещать обязательный автообновлятор и потом не поставить его.

Если в другом чате автообновлятор будет опубликован под названием `FHD_UpdateCheck`, он распознаётся как обязательный. Аналогично поддерживаются `FHD_AutoUpdater` и `FHD_AutoUpdate`.

## Автоматическое определение старого/нового EXE

Программа сама считает SHA-256 у `Rangers.exe` и сверяет его с эталонными хешами в `catalog/exe-hashes.json`. Эталонов старого и нового EXE в этом архиве пока нет. Их нельзя выдумать: автору один раз нужно запустить `REGISTER_EXE_HASHES.cmd`, выбрать оригинальные старый и новый `Rangers.exe` и затем распространять заполненную базу вместе с установщиком.

Если версия не определена, установщик предложит только моды, помеченные как совместимые с любым EXE.

## Безопасность и ограничения

- Игра должна быть закрыта перед установкой.
- ZIP распаковывается штатно; для RAR/7z может потребоваться 7-Zip.
- Моды в основном ставятся в `Mods\FHD_MODS\...`, OnlineChat 󢀔 в `Mods\OtherMods\FHD_OnlineChat\`.
- Моды включаются через `Mods\ModCFG.txt` и начинают действовать при следующем запуске игры, если совместимы с версией игры.
- Существующие файлы перед заменой копируются в `FHD_Setup_Backups` в папке игры; при ошибке применяется откат.
- Загрузка ZIP/RAR выполняется напрямую с Google Drive, поэтому архивы должны быть доступны игрокам по ссылке. Для крупных файлов остаются квоты и ограничения Google.
- Подлинная работа в Windows и внутри игры ещё не проверялась; это подготовленная тестовая версия.

Журнал ошибок: `fhd_setup.log` в папке установщика.
